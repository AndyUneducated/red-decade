**抽屉与全屏的界限（2026-10-11 定）：**
- 有全屏页的只有三类：人物（传记 + 档案可视化 + 足迹地图）、机构（沿革带 + 任职色带 + 上下级）、文献（全文，动辄数千字）。标准是正文超过约 1500 字，或者有自己的可视化。
- 其余四类只用抽屉：事件、概念、派系、结论。它们的内容是几百字的摘要、多声部叙述和关联条目，抽屉放得下。
- 三类全屏条目在别处被点到时，一律先开抽屉预览：300 字以内的摘要、此刻的关键事实，以及“完整传记 → / 机构页 → / 打开全文 →”。只有在本类自己的视图里点（人物目录、机构目录与机构页之间、文献视图的目录），才直接进全屏。搜索框也按这条，选中后开抽屉。
- 引用标记（¶）一律开文献预览，显示来源层级、作者、日期、引用位置、开头 200 字；本站没有全文的来源显示书目信息和外链。
- 关闭抽屉：右上角 ×、再点一次同一个链接、点页面空白处（按钮、链接、输入框、带手形光标的图形不算空白；拖选文字不算）、Esc。
- 抽屉里点开别的条目时，顶部出现“← 上一个条目”，可以退回。
- 实现：`select(ref)` 遇到与当前相同的条目就关闭，`select(ref, true)` 强制打开；空白点击在 `src/App.tsx`。

**配色约定（暗夜模式起）：**
- 所有颜色都用 `src/styles.css` 里的 CSS 变量，CSS 和 TSX 里不再写字面色值；新增颜色先在 `:root` 和 `:root[data-theme='dark']` 两处各定义一个。
- 夜间是暖色调：墨色纸底、米色字、提亮的朱红。状态色按明度反转，“越糟越远离纸色”，所以“死亡”在夜间是灰白而非黑色。
- 画在彩色或深色图形上的“挖空”记号（叉、勾、白字）用 `var(--card)`，不要用 `#fff`。
- 例外：派系颜色来自 `content/factions.yaml`，两种模式共用；思想谱系热力图色阶用 `useTheme()`（`src/lib/theme.ts`）在 JS 里切换。
- 检查：`.probe/shots.mjs <light|dark> <宽> <高> "<hash>|<文件名>"...` 批量截图；`.probe/pixdiff.mjs a.png:b.png` 逐像素比对，改动前后日间截图除顶栏按钮外应完全一致。

**人物字段（MP-0 起，`src/data/schema.ts` PersonSchema）：**
- 身份：`pinyin`；`aka`（字符串，或 `{kind: original|courtesy|art|pen|cover|other, name}`）；`gender`（m/f）；`ethnicity`；`birthplace`（出生地）；`origin`（籍贯）。
- 背景：`classOrigin`（家庭出身）、`classNote`；`education: [{school, from, to, note, cite}]`。
- 履历：`party`（默认中国共产党）、`joinedParty`、`joinedRevolution`；`positions: [{title, org?, orgName?, sys?, from, to, note, cite}]`；`rank: {rank, date, cite}`。
  - `org` 一般不填：构建时先找名称或别名等于 `orgName` 的机构，找不到再找头衔开头最长的别名；如果头衔指向 `orgName` 机构的下属（如“中共中央政治局常委”），取下属。匹配结果写到 `.probe/org-links.txt`，职务时间落在机构存续期外的行标 `!`。只有自动匹配错了才显式填 `org`。
  - `birthAt` / `deathAt`（地点 id）一般也不填，由 `birthplace` / `deathPlace` 自动解析（去掉括号注释，取最长的地名）。
  - 命运节点可加 `place`（地点 id），用于足迹地图上的关押、下放地点。

**机构字段（MP-3 起，`OrgSchema`）：** `kind`（party|state|army|mass|popular|unit）、`level`（central|regional|provincial|basic）、`from`/`to`、`suspended`（名义存在但停止运转的时段）、`places`（驻地随时间）、`under`（上级，随时间）、`links`（本机构 → 对方：lead 领导、found 设立、oppose 对立、merge 并入、takeover 夺权接管、replace 取代）、`factions`、`summary`、`cites`。没有出处的必须标 `verify`。摘要里加引号的字句必须能在所引原文里找到。
  - 负责人名单 `leaders: [{name, title, from, to, person?, faction?, note?, cite?}]`，可以写在机构条目里，也可以写在 `content/leaders/*.yaml`（机构 id → 名单），构建时合并并按起始时间排序。`person` 不用填，构建时按姓名匹配本站人物；`faction` 只给本站未收录、但属于某派系的负责人填（如黄永胜、邱会作、李作鹏、程世清标 `lin`，于会泳、迟群、刘湘屏、鲁瑛标 `ccrg`），供派系掌控图使用。没有 `cite` 的条目一律视为待核。构建检查：任期不早于机构成立、不晚于撤销，人物和派系 id 存在。
  - `sys`（party|gov|army|other）只在职务时间带分错道时填，默认由 `systemOf()` 按机构名和头衔第一项推断。目前只有叶群“林彪办公室主任”填了 `army`。

- 外部标识：`ids: {wikidata, cbdb}`。
- 传记（MP-2）：`bio` 是概述；`life: [{h, from, to, text, cites}]` 是分段生平，每段必须有出处或标 `verify`；`assess` 是评价（多声部，`quote: true` 的逐字核对）；`works` 是著述。

  - 各项日期在生卒之间，起止不倒置；
  - 有死亡细节就必须有卒年；
  - 引用的来源、机构 id 必须存在。
- 构建输出“full bios”是 `life` 至少 3 段的人数，用来追踪 MP-2 进度。
- MP-2 写法：
  - 死后平反记 `rehab`，不进命运轨迹，以免命运矩阵把死者算作“复出”。
  - `life` 段落可以延伸到身后；段内有任何一句来自未入库的来源，整段标 `verify`。
  - 早年骨架指向 `ccp-figures-bios` / `klein-clark-1971`，读过之后再去掉 `verify`。
  - 评价声部：`official1966` 当时官方（含 1974、1976 年文件）；`official1981` 只用于 1981 决议；`officialLater` 后来官方（1977 十届三中全会、1980 年以后的平反通知、审查批语、讣告）；`judicial1980` 显示为“1980 年代审判”，1980–81 年特别法庭和 1982–83 年京沪两地对聂元梓、蒯大富、戚本禹、徐景贤、王秀珍等人的起诉书、判决书共用；1979 年遇罗克再审这类平反性质的改判用 `officialLater`。
