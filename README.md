# 红色年代 · Red Decade

以一手文献为本，可视化 1949–1989 年的中国政治史，以文化大革命为中心。

**在线访问：** https://andyuneducated.github.io/red-decade/

当前完成的是 **1966 年深描切片**：26 篇原始文献全文，56 位人物、67 个事件、85 条关系、21 个概念，以及 10 条从原文逐字比对得出的研究结论。

## 六个视图

- **时间线**：八条泳道（中央高层、思想舆论、群众运动、军队、文教、地方、国际、经济社会），可以从 1949–1989 一直缩放到某一天。底部的“命运脉搏”显示全体人物政治处境随时间的变化。
- **人物网络**：节点颜色表示此刻的政治命运，外圈表示所属派系；连线只显示在当前时刻有效的关系。拖动时间轴，可以看到网络怎样重组。
- **命运矩阵**：每人一行，记录 1965–1980 年的处境：掌权、受批判、被打倒、关押、死亡、平反。
- **思想谱系**：概念 × 文献的词频矩阵，看一个说法在哪份文件里第一次出现、在哪里突然变多。
- **文献**：原文阅读器，可以标注概念与人物、文内查找、按段落编号引用；《五一六通知》与《二月提纲》可以逐条对照。
- **研究**：研究结论及证据、来源登记、待找原文、待核事件。

任何人物、事件、概念都可以点开详情卡片，按 `Ctrl K` 全局搜索。同一事件并列多个声部：原始文件、当时官方、1980 年起诉书、1981 年决议、亲历者、学术研究、本站研究。

## 原则

1. **原文优先。** 每条事实都指向一份一手文献，或者标为“待核”。
2. **引文可核对。** 研究结论中的每一句引文，在构建时都会自动与原文逐字比对。
3. **多声部并列。** 不把不同叙事合成一个“标准答案”；数字类注明口径。
4. **过程可复现。** 检索、抓取、阅读、结论全部记录在 [`research/`](research/README.md)。

## 开发

需要 Node 24+（直接运行 TypeScript 工具脚本）。

```bash
npm install
npm run dev          # 构建数据并启动开发服务器
npm run build        # 校验数据 → 类型检查 → 打包
npm run data:fetch   # 按 research/manifests 抓取维基文库原文
npm run concordance -- 造反 四旧   # 全语料检索
```

| 目录 | 内容 |
|---|---|
| `content/` | 人物、事件、派系、关系、概念、文献（YAML，人工编写） |
| `research/` | 来源清单、抓取日志、研究结论、每日研究日志、待办与方法 |
| `sources/` | 抓取的原文（维基源码与纯文本） |
| `tools/` | 检索、抓取、词频、数据构建与校验 |
| `src/` | 前端（React + TypeScript + D3） |
